# orochibraru/tap

Homebrew formulae for [Penombre](https://github.com/orochibraru/penombre).
Everything here is generated by Penombre's release workflow; open issues and
pull requests there.

## Penombre Sync

The desktop sync client: a tray app keeping local folders in two-way sync with a
Penombre server over WebDAV and rclone.

```bash
brew install orochibraru/tap/penombre-sync
brew services start penombre-sync
```

Canary builds, cut on every merge, are `penombre-sync-canary`; the two conflict,
so uninstall one before installing the other.

`brew services start` launches it now and at every login. Quitting it from the
tray keeps it quit until the next login or `brew services restart`.

Documentation: <https://orochibraru.com/penombre/docs/desktop>.
