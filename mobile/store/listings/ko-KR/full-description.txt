Penombre는 직접 호스팅하는 드라이브입니다. 파일, 사진, 음악, 동영상, 문서를 내 서버에 두니 누구에게도 저장 공간을 빌릴 필요가 없습니다. 이 앱으로 그 드라이브를 휴대폰에서 사용하세요.

사용하려면 Penombre 서버가 필요합니다. Penombre는 무료 오픈 소스이며, 홈 서버나 NAS, VPS에서 컨테이너 하나만 실행하면 됩니다. 설치 방법은 orochibraru.com/penombre에서 확인하세요.

■ 몇 초 만에 로그인
• 서버의 “앱 받기”에 표시되는 QR 코드를 스캔하면 끝. 주소를 입력할 필요가 없습니다.
• 또는 서버 주소를 입력하고 브라우저에서 비밀번호, 패스키, 평소 쓰는 로그인 서비스로 로그인하세요.
• 이메일로 받은 코드로도 로그인할 수 있습니다. 2단계 인증을 지원합니다.

■ 드라이브의 모든 것
• 내 드라이브, 공유 드라이브, 마운트된 볼륨을 수천 개의 파일이 든 폴더에서도 매끄럽게.
• “최근”, “즐겨찾기”, “휴지통”, 카테고리(음악, 이미지, 문서…)를 탭 한 번으로.
• 접근 권한이 있는 모든 곳을 입력하는 대로 바로 검색.
• 파일 업로드, 사진 찍기, 문서를 스캔해 바로 PDF로.
• 이름 변경, 이동, 복사, 복제, 즐겨찾기에 추가, 다운로드, 휴지통으로 이동, 복원.
• 파일의 이전 버전을 재생, 다운로드, 복원.

■ 사진, 음악, 동영상
• 스와이프와 핀치 확대를 지원하는 사진 뷰어. 미리보기를 먼저 보여 주고, 원본은 필요할 때 불러옵니다.
• 파일을 둘러보는 동안에도 계속 재생되는 재생 대기열 음악 플레이어.
• 동영상은 그 자리에서 또는 전체 화면으로. 휴대폰에서 재생할 수 없는 형식이나 연결 속도에 비해 너무 큰 파일은 서버가 720p 또는 480p로 변환합니다.

■ 공유와 알림
• “내 링크”, “공유 문서함”, 그리고 각각 휴지통을 갖춘 공유 드라이브.
• 댓글, 공유, 서명 요청 알림. 제3자 푸시 서비스를 거치지 않고 앱이 서버에서 직접 확인합니다.

■ 내 계정, 내 설정
• 프로필, 비밀번호, 2단계 인증, 세션, API 키, 활동을 웹과 똑같이 관리.
• 강조 색상, 글꼴, 모서리는 계정에 저장되어 웹과 휴대폰에서 똑같이 적용됩니다.
• 13개 언어 지원.

광고 없음, 분석 없음, 저희 서비스 가입도 필요 없습니다. 앱은 내 서버와 연결되고, 파일은 내가 둔 곳에 그대로 있습니다.
